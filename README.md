# Sugarcoated

## Scoring System

Sugarcoated uses a rule-based scoring system.

Each matched ingredient receives points based on its severity:

- High = 5 points
- Medium = 3 points
- Low = 1 point

The total score determines the project's flag level:

- 0–4 = Low
- 5–9 = Moderate
- 10+ = High

The score is an indicator generated by the project's rules and is not a medical diagnosis.
